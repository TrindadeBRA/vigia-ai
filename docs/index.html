INSTALAÇÃO — GRATUITA

Baixe e rode. Sem custo, sem cadastro.

O app desktop já vem com tudo embarcado. Escolha seu sistema:

🍎 macOS
brew tap TrindadeBRA/vigia-ai brew install --cask vigia-ai
🐧 Linux
curl -fsSL .../install.sh | bash
🪟 Windows
Vigia AI Setup.exe
Baixar .exe →

Sem certificado pago de assinatura de código — no primeiro uso o macOS e o Windows podem avisar que o app não é reconhecido. É normal em projetos open source: o código está todo público no repositório.

OU, A PARTIR DO CÓDIGO

git clone https://github.com/TrindadeBRA/vigia-ai.git && cd vigia-ai && ./dev up

Requer Node 22 LTS e Git. Sobe o coletor e o mostrador em http://127.0.0.1:8787/display.
