COMO FUNCIONA — SEM MÁGICA

Um ciclo. Todos os clientes. Sem susto.

  1. 1Tokens ficam no seu computador (Keychain, ~/.codex/auth.json, state.vscdb). O Vigia reusa o login que os apps oficiais já fizeram — igual eles fazem pra desenhar a própria barra de uso.
  2. 2Um ciclo a cada 60s consulta todas as APIs e empurra o mesmo JSON por SSE. Placa e abas não multiplicam chamadas. GET /usage força um ciclo extra.
  3. 3JSON na LAN tem percentuais e datas, nunca o Bearer. Falha numa conta (ok: false) não derruba as outras. HTTP 200 sempre.
Guia técnico completo → Contrato JSON → Arquitetura →
⚠️
LAN only — e isso é proposital.

Os endpoints de cota do Claude, GPT e Cursor não são API pública — são os mesmos que o CLI/IDE já usam neste computador. Não exponha a porta 8787 na internet. A placa nunca guarda tokens — só percentuais e datas. O coletor não é OAuth client: não emite, não renova, só reusa o que já está no host.

PRIVACIDADE
JSON público nunca carrega Bearer, Keychain ou dump de SQLite.
RESILIÊNCIA
Token expirado vira ok: false só naquela conta.
SEM SURPRESA
Endpoints não oficiais podem mudar — a quebra fica isolada.

INSTALAÇÃO — 1 COMANDO

De zero ao mostrador em segundos.

Um único comando clona o repo, instala as dependências, compila a firmware, grava na ESP32, sobe o servidor e cria o atalho na Área de Trabalho / Menu Iniciar — pronto para duplo clique.

TERMINAL
COPIAR E COLAR
curl -fsSL https://raw.githubusercontent.com/TrindadeBRA/vigia-ai/main/install-scripts/install.sh | bash
