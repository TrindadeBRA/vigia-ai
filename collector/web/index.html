Painel do coletor

Este programa roda no Mac, fala com Claude, Cursor e OpenRouter, e publica um JSON na sua Wi-Fi. A placa ESP32 só baixa esse JSON (porcentagens e datas). Tokens nunca vão para a tela.

  1. 1

    Contas

    Claude e Cursor: deixe vazio se os apps já estão logados. OpenRouter: cole a key.

  2. 2

    Copie a URL

    É o endereço da LAN que a placa usa (não use 127.0.0.1 na ESP32).

  3. 3

    Cole no firmware

    Em src/secrets.h, no USAGE_URL, e grave a placa.

URL que a placa usa

A ESP32 está na mesma Wi-Fi e, a cada minuto, pede as cotas neste endereço. Cole em src/secrets.h no campo USAGE_URL.

Contas das IAs

      
O coletor tenta o login que já existe no computador. Só cole token se o status pedir.

      

        

          

            
Claude

            
          

          
Mostra a cota da assinatura (sessão 5 h e semana), a mesma do Claude Code. Não use a key sk-ant-… — isso é a API paga por token, outra fatura.

          

          

            Colar token (só Docker / outro PC)
            
Não cole claude setup-token (dá 403 sem escopo user:profile). No Mac, apague o token e use o Claude Code logado.

            
            

              
              
            

          

        


        

          

            
Cursor

            
          

          
Mostra o % do plano (Cursor Models / Other Models). Não existe API key oficial disso: o coletor lê o login que o app Cursor já salvou neste Mac.

          

          

            Colar token (só se o app não estiver neste PC)
            
Com o Cursor aberto e logado, deixe vazio. Token é o JWT de sessão, não uma key de API do Cursor.

            
            

              
              
            

          

        


        

          

            
OpenRouter

            
          

          
Mostra créditos da conta inteira. Aqui sim é uma API key normal. Crie em openrouter.ai/settings/keys e cole abaixo.
